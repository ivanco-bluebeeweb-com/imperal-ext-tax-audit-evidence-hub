# Start an evidence-readiness case — готовые демо-данные

> **Назначение:** безопасный вымышленный набор для первой демонстрации Tax & Audit Evidence Hub.
>
> Используй **один** языковой блок за раз. `DemoCo` — вымышленная организация. Эти данные не являются налоговой консультацией, налоговым решением, аудит-выводом, заявлением или разрешением на подачу документов.

## Поля формы

| Поле в интерфейсе | Что означает |
|---|---|
| **Case name** | Понятное название подготовительного кейса |
| **Organization name** | Организация или клиент |
| **Period** | Период, который задал человек |
| **Request type** | Цель подготовки, не налоговое решение |
| **Owner** | Человек, который координирует подготовку |
